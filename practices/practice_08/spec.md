# Спецификация интерфейса «Подборки ВкусВилла» (практика 8)

**Дата:** 2026-11-17
**Основа:** сервис `practices/practice_04/collections` (Go, API без изменений) и
`practices/practice_04/docs/specs/2026-10-22-vkusvill-collections.md`.
**Что делаем:** новый фронтенд на React + TypeScript + Vite + Tailwind +
shadcn/ui вместо самописного `web/app.js`. Бэкенд и контракт API не меняются.

Макет задаёт внешний вид, эта спецификация описывает поведение. Каждое правило
ниже проверяется тестом (см. раздел 7).

## 1. Пользователь и сценарий

**Кто:** человек, который выбирает, что приготовить, и хочет быстро собрать
корзину во ВкусВилле.

**Основной сценарий (от действия до результата):**
открыть страницу → ввести тег в форму поиска («ужин») → нажать «Найти» →
увидеть карточки только с этим тегом → нажать «В корзину» → получить ссылку
на корзину ВкусВилла в новой вкладке.

**Дополнительные сценарии:** сохранить подборку в избранное и найти её на
вкладке «Избранное»; выбрать тег чипом; сбросить фильтр.

## 2. Экраны и состояния

| Код | Состояние | Что видит пользователь |
| --- | --- | --- |
| S1 | Загрузка | Скелетоны карточек, форма и чипы недоступны для отправки, статус «Загружаем подборки…» |
| S2 | Список | Сетка карточек, статус «Показаны подборки по тегу «X»» или «Показаны все подборки» |
| S3 | Пусто по тегу | «По тегу «X» ничего не найдено» и кнопка «Сбросить фильтр» |
| S4 | Пусто без фильтра | «Подборок пока нет» и кнопка «Обновить» |
| S5 | Пустое избранное | «Пока пусто. Добавьте подборку в избранное — она останется здесь.» |
| S6 | Ошибка 500 | «Не удалось загрузить подборки по тегу «X». Попробуйте ещё раз.» и «Повторить» |
| S7 | Ошибка 400 | «Не удалось применить фильтр.» и «Сбросить фильтр» |
| S8 | Отправка корзины | Кнопка «Собираем корзину…», недоступна |
| S9 | Ошибка корзины | Сообщение рядом с карточкой, кнопка снова доступна |
| S10 | Корзина готова | Статус «Корзина готова» и ссылка «Открыть корзину во ВкусВилле» у карточки |

## 3. Правила формы «Поиск по тегу»

Форма: поле «Тег» (видимая подпись `<label>`), кнопка «Найти», кнопка
«Сбросить». Подсказки в поле берутся из `tags` ответа API.

1. **Обязательность.** Пустое поле или строка из одних пробелов: запрос не
   отправляется, под полем сообщение «Введите тег», поле получает
   `aria-invalid="true"` и фокус.
2. **Длина.** После обрезки пробелов больше 64 символов (по символам Unicode):
   запрос не отправляется, сообщение «Тег не длиннее 64 символов».
3. **Отправка.** Работает и по кнопке, и по Enter. Перед запросом значение
   обрезается по краям.
4. **Защита от повторной отправки.** Пока запрос выполняется, кнопка «Найти»
   недоступна, а повторные клики и Enter игнорируются. На сервер уходит ровно
   один запрос. После ответа форма снова доступна.
5. **Успех.** В поле подставляется канонический `active_tag` из ответа
   (например, «Ужин» превращается в «ужин»), показаны карточки, статус успеха.
6. **Пустой ответ.** `200` и `collections: []` показывают S3. Это не ошибка.
7. **Ошибка 500.** Введённый текст остаётся в поле. Показано S6 с кнопкой
   «Повторить»; повтор отправляет тот же тег.
8. **Ошибка 400.** Введённый текст остаётся, показано S7.
9. **Сброс.** Очищает поле и ошибки, загружает все подборки, фокус
   возвращается в поле.
10. **Чипы.** Выбор чипа вписывает тег в поле и отправляет форму; повторное
    нажатие на активный чип снимает фильтр. Во время загрузки чипы не
    срабатывают.
11. **Поздние ответы.** Ответ на устаревший запрос игнорируется.

## 4. Правила карточек, избранного и корзины

12. **Избранное.** Кнопка-сердце имеет `aria-pressed`. Во время запроса она
    недоступна. При ошибке состояние не меняется, показано сообщение.
13. **Вкладка «Избранное».** Загружает `/api/favorites`. Удаление подборки
    убирает карточку; при пустом списке показано S5.
14. **Корзина.** Кнопка «В корзину» на время запроса недоступна и показывает
    «Собираем корзину…»; запрос `POST /api/collections/{id}/cart` уходит один
    раз даже при двойном клике. При успехе ссылка открывается в новой вкладке, а у
    карточки остаётся статус «Корзина готова» и ссылка «Открыть корзину во
    ВкусВилле» (на случай блокировки всплывающего окна). При ошибке показано S9,
    кнопка снова доступна.

## 5. Доступность и адаптивность

15. У каждого поля есть подпись; сообщения об ошибке связаны с полем через
    `aria-describedby`; статусы объявляются через `role="status"`.
16. Основной сценарий выполняется только с клавиатуры (Tab, Enter, Space).
17. Видимый индикатор фокуса у всех интерактивных элементов.
18. Сетка: одна колонка до 720 px, две до 1100 px, три выше; на ширине 320 px
    нет горизонтальной прокрутки; элементы управления не меньше 44×44 px.
19. При `prefers-reduced-motion` анимации отключены.

## 6. Контракт API (формат ответов для тестовых данных)

Тестовые ответы сервера (MSW и Playwright) повторяют реальный формат.

`GET /api/collections[?tag=...]` → `200`:

```json
{
  "collections": [{
    "id": "dinner-500-1792666479", "slug": "dinner-500",
    "title": "Ужин на двоих", "subtitle": "Простой ужин без лишних трат",
    "template": "dinner-500", "budget": 500, "total": 480,
    "items": [{"id": 123, "name": "Куриное филе", "price": 250, "unit": "кг",
               "rating": 4.8, "quantity": 1, "url": "https://vkusvill.ru/..."}],
    "tags": ["ужин", "бюджет"],
    "created_at": "2026-10-23T12:00:00Z", "generation": 1792666479
  }],
  "favorites": ["friends-lunch-1792666479"],
  "tags": ["бюджет", "завтрак", "перекус", "ужин"],
  "active_tag": "ужин"
}
```

| Запрос | Ответ |
| --- | --- |
| неизвестный тег | `200`, `collections: []`, `active_tag` = обрезанный запрос |
| тег длиннее 64 | `400 {"error":"tag is too long"}` |
| ошибка чтения | `500 {"error":"cannot load collections"}` |
| `GET /api/favorites` | `200 {"collections":[...]}` |
| `PUT /api/favorites/{id}` | `200 {"favorite":true,"id":"..."}`, `404 {"error":"collection not found"}` |
| `DELETE /api/favorites/{id}` | `200 {"favorite":false,"id":"..."}` |
| `POST /api/collections/{id}/cart` | `200 {"url":"https://vkusvill.ru/mobile?basket&share=..."}`, `502 {"error":"cannot create cart link"}` |

Ошибки всегда JSON `{"error":"..."}`; массивы в успешных ответах никогда `null`.
