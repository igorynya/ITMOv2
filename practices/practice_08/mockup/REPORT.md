## 2. Стек и компоненты (по отчёту Replit)

- React + TypeScript, Vite (предпросмотр в `mockup-sandbox`), Tailwind CSS и
  локальный CSS, иконки lucide-react.
- **shadcn/ui использован:** Alert, Badge, Button, Card, Input, Label, Select,
  Skeleton, Tabs. Это совпадает с запросом переиспользовать готовые компоненты.

## 3. Первый вариант

Одностраничный экран: заголовок, переключатель демонстрационных состояний,
вкладки «Все»/«Избранное», поиск по тегу, популярные теги, карточки подборок.
Скриншоты: [`v1/`](v1/). В первой версии в карточках были «порции/время» и
иконки-рецепты (в API таких данных нет).

## 4. Ревью первого варианта (мои замечания)

1. Выдуманные поля «2 порции · 30 минут» в карточках.
2. Нет состояний: ошибка 400, ошибка и загрузка корзины; кнопка «В корзину»
   не видна.
3. На вкладке «Избранное» остались форма и чипы тегов.
4. Дубли текста в успехе и в «ничего не найдено».
5. При отправке видны старые карточки и счётчик.
6. Счётчик «0 подборки».
7. Мелочи: плотный letter-spacing, «Избранное(0)», нет счётчика символов.
8. Нет перехода в корзину магазина (состояние «Корзина готова»).

## 5. Хронология запросов к Replit

1. Исходный бриф (промпт из `prompt.md`): прототип с поиском по тегу, вкладками,
   избранным, карточками, состояниями, адаптивностью. Результат: компонент
   `FoodCollections` с переключателем состояний.
2. Отдельный вариант «короткий сценарий выбора меню» (`MenuJourney`): шаги
   повод/порции → подборка → список продуктов. Не входит в основной сценарий.
3. Мобильный вариант (`MobileFoodCollections`): компактные карточки и
   раскрытие списка товаров. Не входит в основной сценарий.
4. Правка по замечанию 1: убраны «порции/минуты» и иконки. Скриншот запроса:
   [`iterations/01-prompt-remove-servings.png`](iterations/01-prompt-remove-servings.png).
   Результат: исправлено.
5. Правка по замечаниям 2–8 одним запросом. Результат: см. таблицу ниже.
6. Запрос отчёта (этот документ основан на нём).

## 9. Ограничения и расхождения

- Прототип не делает реальных запросов: поиск, цены, корзина и ошибки
  демонстрационные; избранное и корзина магазина не подключены.
- Реализуется в коде приложения (а не берётся из прототипа): валидация, защита от
  повторной отправки, состояния корзины S8–S10, реальные запросы к API,
  токены радиусов и семантика доступности (`aria-*`).
- Не вошло в основной сценарий: варианты `MenuJourney` (порции) и
  `MobileFoodCollections` создавались отдельно; порции в API отсутствуют.
