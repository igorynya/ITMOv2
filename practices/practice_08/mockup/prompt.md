# Промпт для макета (v0 / Replit Agent / Figma Make)

Сделай интерактивный прототип одностраничного веб-приложения «Подборки продуктов»
на русском языке. Стек: React + TypeScript + Tailwind CSS + shadcn/ui. Используй
готовые компоненты shadcn/ui (Button, Input, Label, Card, Badge, Tabs, Skeleton,
Alert), собственные кнопки и поля не рисуй. Это учебный проект, логотипы и
фирменные элементы реальных брендов не используй.

## Для кого и зачем
Человек выбирает, что приготовить, находит подборку продуктов по тегу
(«ужин», «завтрак», «бюджет») и открывает корзину в магазине одним нажатием.

## Экран
1. Шапка: заголовок «Что приготовить сегодня?», короткий подзаголовок, кнопка
   «Ещё подборки».
2. Вкладки «Все» и «Избранное» (на «Избранное» счётчик).
3. Форма «Поиск по тегу»: поле с видимой подписью «Тег», кнопки «Найти» и
   «Сбросить». Ниже ряд чипов-тегов (выбор чипа вписывает тег в поле).
4. Сетка карточек подборок: название, подзаголовок, теги (Badge), 3–6 товаров с
   ценой, итоговая сумма и лимит бюджета, кнопка-сердце «В избранное»,
   кнопка «В корзину».
5. Подвал с пояснением, что проект учебный.

## Состояния (покажи каждое отдельным вариантом, переключатель состояний в
## углу прототипа)
- Начальная загрузка: скелетоны карточек, форма и чипы неактивны.
- Список подборок (успех) со статусом «Показаны подборки по тегу «ужин»».
- Валидация: пустое поле — «Введите тег»; больше 64 символов — «Тег не длиннее
  64 символов». Поле подсвечено ошибкой, сообщение под полем.
- Отправка формы: кнопка «Найти» неактивна, виден индикатор.
- Пусто по тегу: «По тегу «X» ничего не найдено» и кнопка «Сбросить фильтр».
- Пустое избранное: «Пока пусто. Добавьте подборку в избранное».
- Ошибка загрузки: Alert «Не удалось загрузить подборки. Попробуйте ещё раз.»
  и кнопка «Повторить»; введённый в поле текст остаётся.
- Кнопка «В корзину» в процессе: «Собираем корзину…», неактивна.
- Ошибка корзины: сообщение у карточки, кнопка снова активна.
- Корзина готова: статус «Корзина готова» и ссылка «Открыть корзину во ВкусВилле ↗»
  (новая вкладка) у карточки.

## Оформление
Палитра: фон #fbfbf6, текст #122017, акцент зелёный #1b7a3d, светлый акцент
#d8f26b, ошибка #e24a2a, границы #d8dccf, приглушённый текст #5b675f.
Системный шрифт без засечек, крупный заголовок, скругления у кнопок и чипов,
единая шкала отступов (4/8/16/24). Цвета задай через CSS-переменные темы
shadcn/ui, а не в каждом компоненте.

## Адаптивность и доступность
Одна колонка до 720 px, две до 1100 px, три выше; на ширине 320 px без
горизонтальной прокрутки. Все поля с подписями, видимая рамка фокуса, контраст
текста не ниже 4.5:1, элементы управления не меньше 44×44 px.
