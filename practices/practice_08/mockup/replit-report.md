# Отчёт по прототипу «Подборки продуктов»

Отчёт описывает основной прототип `FoodCollections` и два созданных рядом варианта. Поиск, цены, корзина и ошибки здесь демонстрационные: изменения backend/API не выполнялись.

## 1. Стек и компоненты

- **React + TypeScript**: интерфейсы написаны в `.tsx`, локальное состояние — React hooks.
- **Vite**: предпросмотр компонентов в `artifacts/mockup-sandbox`.
- **Tailwind CSS и локальный CSS**: для отдельных элементов используются utility-классы, а основная тема и раскладка заданы CSS-файлами прототипов.
- **shadcn/ui — да.** В основном компоненте используются `Alert`, `AlertDescription`, `Badge`, `Button`, `Card`, `Input`, `Label`, `Select`, `SelectContent`, `SelectItem`, `SelectTrigger`, `SelectValue`, `Skeleton`, `Tabs`, `TabsList`, `TabsTrigger`.
- **lucide-react**: иконки `ArrowRight`, `Check`, `CircleAlert`, `CookingPot`, `Heart`, `Leaf`, `RefreshCw`, `ShoppingBasket`, `Sparkles`.

## 2. Первый вариант

Первым был предложен одностраничный русскоязычный экран: заголовок и краткое описание, переключатель демонстрационных состояний, вкладки «Все» и «Избранное», поиск по тегу, популярные теги и карточки подборок с продуктами, ценами, итогом, лимитом, избранным и действием «В корзину». Визуальная основа — светлый фон, тёмно-зелёный текст, зелёные кнопки и лаймовые акценты; макет адаптируется к узким экранам.

В первоначальных карточках были порции, время приготовления и тематические иконки. Позже они удалены по запросу: этих данных нет в API. Теперь карточка содержит название, подзаголовок, теги, список товаров (название, количество, цена), итог, лимит бюджета, сердце и кнопку корзины.

## 3. Хронология запросов

1. **Исходный brief:** создать интерактивный прототип «Подборки продуктов» на русском языке с поиском и тегами, вкладками, избранным, карточками, состояниями интерфейса, адаптивностью и доступными элементами.  
   **Изменение:** создан основной компонент `FoodCollections` с локальными примерами подборок и переключателем состояний.
2. **Короткий сценарий выбора меню:** сделать отдельный вариант в новом компоненте и canvas-фрейме, сохранив русский язык и интеракции.  
   **Изменение:** создан `MenuJourney` с шагами выбора повода и порций, выбора подборки и просмотра списка продуктов; действия и подтверждение локальные.
3. **Мобильный вариант:** создать отдельный компонент и фрейм, адаптировать карточки для узкого экрана, сохранить доступность и интеракции.  
   **Изменение:** создан `MobileFoodCollections` с компактными карточками и доступным раскрытием списка товаров.
4. **Убрать данные, которых нет в API:** удалить из карточек порции, время и иконки-рецепты; оставить только перечисленные поля товаров и подборки.  
   **Изменение:** названия товаров, количества и цены отображаются отдельно; неподтверждённые поля убраны из основного компонента.
5. **Дополнить состояния и поведение основного фрейма:** добавить ошибку фильтра и состояния корзины; скрывать поиск и теги в избранном; устранить повтор результата; показывать скелетоны при отправке; исправить счётчик, заголовок и счётчик символов.  
   **Изменение:** все эти состояния и правила добавлены в `FoodCollections`; состояние корзины применяется к первой видимой карточке.
6. **Сформировать отчёт в Markdown.**  
   **Изменение:** этот документ.

## 4. Состояния: реализовано и не реализовано

В переключателе основного прототипа реализованы следующие **UI-состояния**:

| Состояние | Поведение в прототипе |
|---|---|
| Успех | Показывается результат фильтрации и число подборок. |
| Загрузка | Показываются скелетоны; элементы поиска и чипы отключены. |
| Пустой тег / тег длиннее 64 символов | Показывается валидация поля. |
| Отправка запроса | Кнопка поиска показывает индикатор, вместо карточек — скелетоны, счётчик скрыт. |
| Нет результатов | Сообщение о результате показывается в статусной плашке один раз; отображается пустое состояние. |
| Ошибка 400 | Плашка «Не удалось применить фильтр.», кнопка «Сбросить фильтр»; введённый тег сохраняется до нажатия кнопки. |
| Пустое избранное | Показывается пустое состояние; на вкладке избранного поиск и чипы скрыты. |
| Ошибка загрузки | Показывается ошибка и кнопка повтора; повтор демонстрационно переводит интерфейс к успеху. |
| Корзина · загрузка | Карточки остаются на месте; у первой видимой карточки кнопка «Собираем корзину…» отключена. |
| Корзина · ошибка | Под первой видимой карточкой показано «Не получилось собрать корзину. Попробуйте ещё раз.»; кнопка «В корзину» активна. |

Счётчик склоняет подпись как «0 подборок», «1 подборка», «2–4 подборки», «5+ подборок» и скрывается во время загрузки/отправки, при ошибках и валидации. У поля тега отображается `N/64`.

**Что не подключено:** реальные сетевые запросы, настоящий ответ API 400, фактическая загрузка подборок, добавление товаров в магазинную корзину и сохранение избранного. Эти состояния выбираются вручную в прототипе или имитируются локально. Успешное нажатие «В корзину» показывает временное локальное подтверждение; отдельного пункта «Корзина · успех» в переключателе нет.

## 5. Цвета, шрифт, радиусы и отступы

### Основной вариант `FoodCollections`

В `artifacts/mockup-sandbox/src/components/mockups/food-collections/_group.css` заданы основные CSS-переменные:

| Переменная | Значение |
|---|---|
| `--fc-background` | `#fbfbf6` |
| `--fc-text` | `#122017` |
| `--fc-primary` | `#1b7a3d` |
| `--fc-accent` | `#d8f26b` |
| `--fc-error` | `#e24a2a` |
| `--fc-error-ink` | `#a8321c` |
| `--fc-border` | `#d8dccf` |
| `--fc-muted` | `#5b675f` |

Там же определены производные `--fc-surface`, `--fc-soft`, `--fc-accent-soft`, `--fc-error-soft` и тени, а также HSL-переменные темы shadcn/ui (`--background`, `--foreground`, `--primary`, `--accent`, `--destructive`, `--border`, `--ring` и другие).

- **Шрифт:** системный стек `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `sans-serif`, задан на `.fc-app`.
- **Отступы:** базовые переменные `--fc-space-1: 4px`, `--fc-space-2: 8px`, `--fc-space-4: 16px`, `--fc-space-6: 24px`. Дополнительные `gap` и `padding` указаны непосредственно в правилах классов.
- **Радиусы:** отдельных переменных радиуса нет — значения заданы в CSS правилах. Например, карточки — `22px`, поля ввода — `14px`, статусные плашки — `16px`, круглые кнопки/чипы — `999px`, круглые элементы — `50%`.
- Основные интерактивные элементы имеют минимальную высоту `44px`; текущий главный заголовок использует `letter-spacing: -.035em`.

### Два дополнительных варианта

- **`MenuJourney.css`:** цвета заданы переменными `--mj-paper: #f4f0e5`, `--mj-paper-deep: #e9e3d4`, `--mj-card: #fbf9f2`, `--mj-ink: #183c3b`, `--mj-muted: #687b72`, `--mj-line: #d8d6c6`, `--mj-green: #234c45`, `--mj-coral: #d65d43`, `--mj-citrus: #d8df76`. Шрифты — `DM Sans`, `Fraunces` и `IBM Plex Mono` (подключены в начале CSS-файла). Радиусы и отступы задаются непосредственно в правилах CSS, например радиусы `16px`, `13px`, `999px`, а также круглые элементы; общих переменных отступов нет.
- **`mobilefoodcollections.css`:** цвета заданы `--mfc-ink: #25352e`, `--mfc-muted: #718078`, `--mfc-green: #376c53`, `--mfc-lime: #dce98a`, `--mfc-paper: #f4f4ed`, `--mfc-card: #fffefa`, `--mfc-line: #dfe3d7`, `--mfc-soft: #edf0e6`, `--mfc-rust: #b75237`. Шрифт — `DM Sans` с запасными `Avenir Next` и системным sans-serif. Радиусы и отступы также заданы непосредственно в CSS; например, карточки — `18px`, поле переключателя — `13px`, область кнопки переключателя — `9px`. Ширина мобильной колонки ограничена `560px`.
