## API (формат для тестовых ответов, из документации)

- `GET /api/collections[?tag=...]` -> `{collections:[{id,slug,title,subtitle,
  template,budget,total,items:[{id,name,price,unit,rating,quantity,url}],tags,
  created_at,generation,cart_url?}],favorites:[id],tags:[...],active_tag}`.
  Неизвестный тег: 200 и `collections: []`. Тег до 64 символов (`MaxTagLength`),
  иначе `400 {"error":"tag is too long"}`; 500 `{"error":"cannot load collections"}`.
- `GET /api/favorites` -> `{collections:[...]}`; `PUT/DELETE /api/favorites/{id}` ->
  `{favorite:bool,id}`; 404 `{"error":"collection not found"}` для PUT.
- `POST /api/collections/{id}/cart` -> `{url:"https://vkusvill.ru/..."}`;
  502 `{"error":"cannot create cart link"}`.
- Cookie `vv_visitor` выдаёт сервер; ошибки всегда JSON `{"error":"..."}`.
