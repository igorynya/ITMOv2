## Master Prompt v1

```
Role: AI-reviewer. INPUTS: @practices/practice_01/TRAINING_PR.diff. RETURN:summary in russian language, заполни файлы @practices/practice_01/context.md, @practices/practice_01/problem.md, @practices/practice_01/prompts.md. Forbidden: Check PR and summary riscs and error, заполнив файлы, которые я тебе дал on russian language, stop if you find 3 riscs. Не придумывай правила. Flow: candidate -> evidence -> check. Нет evidence -> check. Done: evidence + check для каждого риска и заполненные файлы
```

Соберите здесь контракт второго запуска. Не копируйте все документы целиком — ставьте ссылки на файлы и переносите только необходимый для задачи контекст.

### 1. Цель и роль

- Цель: базовое ревью изменений в `TRAINING_PR.diff` и фиксация рисков по фактам diff.
- Роль AI: AI‑ревьюер, который перечисляет риски по схеме candidate -> evidence -> check, без выдумывания правил.

### 2. Входы и источники

- Обязательный вход: файл `TRAINING_PR.diff`.
- Разрешённые файлы и источники: только содержимое diff и уже заполнённый контекст.
- Context Pack — факты, правила, примеры и ограничения: см. `context.md` (секции Факты и правила, Формат входа/результата).

### 3. Задача и артефакты

- Что сделать: выявить до трёх рисков на основе diff и зафиксировать evidence + check; обновить `context.md`, `problem.md`, `prompts.md`.
- Что вернуть: краткую сводку на русском и ссылки/записи в артефактах.

### 4. Формат результата

- Структура ответа: список рисков, каждый в формате candidate -> evidence -> check.
- Ограничения объёма: остановиться после трёх рисков.

### 5. Полномочия и запреты

- Разрешено: читать diff, заполнять указанные файлы.
- Запрещено: добавлять правила, не подтверждённые diff; выходить за пределы указанных артефактов.

### 6. Рабочий процесс и остановка

- Шаги: candidate -> evidence -> check; затем заполнение артефактов; финальная проверка ссылок.
- Когда остановиться и запросить человека: при достижении 3 рисков или при отсутствии достаточного evidence.

### 7. Проверки и evidence

- Как проверять утверждения: ссылками на строки diff и описание поведения по коду.
- Какое evidence сохранить: цитаты строк diff или участок функции с указанием файла и строк.

### 8. Definition of Done

- Задача закончена, когда: перечислены до 3 рисков с evidence и check, и обновлены `context.md`, `problem.md`, `prompts.md`.
