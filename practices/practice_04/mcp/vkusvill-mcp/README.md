# VkusVill MCP (локальная упрощённая версия)

Локальный MCP-сервер (stdio), который проксирует официальный
`https://mcp.vkusvill.ru/mcp` и отдаёт агенту четыре простых инструмента.
Будущий микросервис может либо запускать этот сервер, либо импортировать
логику из `src/vv.js`.

## Инструменты

| Tool | Что делает |
| --- | --- |
| `vv_search_products` | Поиск по каталогу, компактные карточки: id, название, цена, рейтинг, ссылка |
| `vv_product_details` | Полная карточка товара по id |
| `vv_create_cart_link` | Ссылка на корзину из явного списка `{id, quantity}` |
| `vv_build_cart` | По списку запросов выбирает популярный товар с рейтингом не ниже порога и сразу создаёт ссылку на корзину |

`vv_build_cart` сортирует выдачу по популярности, отбрасывает товары с рейтингом
ниже порога, сначала исключает весовые позиции (`unit = "кг"`), затем берёт
первый подходящий товар. Рейтинг по умолчанию — 4.5.

## Установка и запуск

```bash
cd practices/practice_04/mcp/vkusvill-mcp
npm install
npm test
npm run demo
```

`npm run demo` собирает тестовую корзину из промо-страницы ВкусВилла
(два круассана, сырники, сметана, сгущёнка, голубика, дрип-кофе, апельсиновый
сок; рейтинг не ниже 4.7) и печатает ссылку на корзину.

Свой список:

```bash
node src/demo.js "круассан:2" "сырники:1" "сметана:1" --min-rating=4.7
```

Формат аргумента — `запрос:количество`.

## Подключение к OpenCode

Сервер уже прописан в корневом `opencode.json` как MCP `vkusvill`.
После перезапуска OpenCode инструменты `vv_*` доступны агенту.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `VV_MCP_URL` | `https://mcp.vkusvill.ru/mcp` | Адрес удалённого MCP |
| `VV_ACCESS_TOKEN` | нет | Bearer-токен OAuth для персонализированных инструментов |
| `VV_MCP_TIMEOUT_MS` | `45000` | Таймаут одного вызова |

Публичные инструменты работают без авторизации. Для доступа к аккаунту нужен
OAuth 2.0 + PKCE: клиент регистрируется на
`https://vkusvill.ru/oauth/registration/`, учётные данные приходят на почту.
Готовый access token можно положить в `VV_ACCESS_TOKEN`; полный OAuth-флоу
в этой упрощённой версии не реализован.

## Ограничения

- Официальный сервер ограничивает выдачу 10 товарами на страницу и
  rate limit порядка 60 запросов в минуту.
- Наличие товара возвращается только для авторизованного пользователя.
- Ссылка на корзину не оформляет заказ: она открывает корзину с товарами.
