## 8. D8. Проверка пустого `id` недостижима

В `addFavorite` и `removeFavorite` есть проверка:

```go
id := r.PathValue("id")
if id == "" {
    writeError(w, http.StatusBadRequest, "collection id is required")
    return
}
```

Но маршруты объявлены как `PUT /api/favorites/{id}` и
`DELETE /api/favorites/{id}`. Шаблон `{id}` не совпадает с пустым
сегментом, поэтому `PUT /api/favorites/` получает `404` от `ServeMux`,
и ветка `400` не выполняется. Проверено отдельным запуском
`http.ServeMux` с тем же шаблоном.

На поведение UI это не влияет: пустой `id` не приходит из интерфейса.
В [02-api.md](02-api.md) описание исправлено: для пустого `id` указан
`404`, а не `400`.

**Что сделать:** либо убрать недостижимую ветку, либо добавить маршрут
без `{id}`, если `400` действительно нужен.
