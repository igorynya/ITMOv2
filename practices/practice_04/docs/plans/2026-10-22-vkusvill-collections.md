# Подборки ВкусВилла: упрощённый план

**Дата:** 2026-10-22
**Статус:** реализовано (MVP)
**Цель:** небольшой учебный проект для проверки MCP ВкусВилла, без
продакшен-сложности.

## Упрощения относительно первой версии

- Генерация только при старте, без фонового планировщика и обновления раз
  в 6 часов.
- 18 шаблонов по одному варианту вместо 30–40 подборок.
- HTTP на stdlib `net/http` вместо chi.
- Кэш ссылки на корзину остался; отдельного rate limit на входящие запросы нет.
- Фронтенд без внешних шрифтов и сложных анимаций.
- Нет очистки старых поколений и OAuth.

## Архитектура

```
cmd/server ── config ── store (SQLite)
    │            │
    │            └── generator ── mcp ──► mcp.vkusvill.ru
    │
    └── httpapi ── web (embed)
```

Генерация выполняется до запуска HTTP-сервера. При ошибке MCP сервис
поднимает последнее активное поколение из SQLite. Если активного поколения
нет, процесс завершается с ошибкой.

## Проверка

```sh
cd practices/practice_04/collections
make test
make vet
make run
```

Ручной сценарий:

1. Открыть `http://localhost:8080`, дождаться карточек.
2. Нажать «Ещё подборки» — выборка меняется.
3. Добавить карточку в избранное, перезагрузить страницу, открыть вкладку
   «Избранное».
4. Нажать «В корзину» — открывается новая вкладка ВкусВилла.
5. Повторное нажатие возвращает закэшированную ссылку.

## Известные ограничения

- Первая генерация занимает около минуты (60+ запросов к MCP).
- Бюджетные шаблоны могут пропускаться, если реальные цены не помещаются
  в лимит; генерация продолжается, пока собрано ≥ 10 подборок.
- Ссылка на корзину публичная и не привязана к аккаунту.
- Старые поколения остаются в БД.
