# Feature Specification: Фильтр подборок по тегу (интерфейс)

**Feature Branch**: N/A — спека лежит в `practices/practice_05/spec_ui`

**Created**: 2026-10-23

**Status**: Draft

**Input**: User description: "Опиши только пользовательское поведение интерфейса фильтра подборок по тегу: выбор тега, сброс, состояния загрузки/успеха/пустоты/ошибки, вкладка «Избранное», доступность с клавиатуры и мобильная прокрутка чипов."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Выбрать тег (Priority: P1)

Пользователь на вкладке «Все» видит над сеткой строку чипов: «Все» и доступные теги. Он активирует один тег и получает только подборки с этим тегом.

**Why this priority**: это основная ценность фичи — быстро оставить на экране нужные подборки.

**Independent Test**: открыть вкладку «Все», активировать тег «ужин», убедиться, что в сетке только подборки с этим тегом, чип выделен, а сброс возвращает все подборки.

**Acceptance Scenarios**:

1. **Given** вкладка «Все» и загруженный список тегов, **When** пользователь активирует тег, **Then** интерфейс показывает состояние загрузки, блокирует повторный запуск фильтра, а после успеха показывает только подборки с выбранным тегом.
2. **Given** активен тег «ужин», **When** пользователь активирует «завтрак», **Then** активным становится только «завтрак», а сетка содержит только подборки «завтрак»; одновременный выбор двух тегов невозможен.
3. **Given** по тегу найдено меньше 12 подборок, **When** загрузка завершилась, **Then** показываются все найденные карточки без пустых мест и без добора из других тегов.
4. **Given** по тегу не найдено ни одной подборки, **When** загрузка завершилась, **Then** показывается пустое состояние с названием тега и действием сброса.

---

### User Story 2 - Сбросить фильтр и вернуться к «Все» (Priority: P1)

Пользователь может снять фильтр одним действием: повторным нажатием на активный тег, нажатием на «Все» или кнопкой сброса в пустом состоянии.

**Why this priority**: без понятного выхода из фильтра пользователь может застрять на пустом результате.

**Independent Test**: активировать любой тег, затем снять фильтр каждым из доступных способов и убедиться, что показываются все подборки.

**Acceptance Scenarios**:

1. **Given** активен тег, **When** пользователь повторно активирует этот же чип, **Then** фильтр снят, активен «Все», загружены все подборки.
2. **Given** активен тег, **When** пользователь активирует «Все», **Then** фильтр снят, активен «Все», загружены все подборки.
3. **Given** пустой результат по тегу, **When** пользователь активирует «Сбросить фильтр», **Then** фильтр снят, активен «Все», загружены все подборки, фокус переходит на «Все».
4. **Given** идёт загрузка, **When** пользователь пытается повторно активировать чип, **Then** второй запрос не запускается.

---

### User Story 3 - Понятные состояния загрузки, успеха, пустоты и ошибки (Priority: P1)

На каждом шаге пользователь понимает, что происходит: идёт загрузка, подборки найдены, ничего не найдено или произошла ошибка, которую можно повторить.

**Why this priority**: фильтрация зависит от сервера, поэтому состояния и восстановление после ошибки — часть основного сценария.

**Independent Test**: с помощью задержки и недоступности сервера пройти все состояния и убедиться, что каждое имеет текст и доступное действие.

**Acceptance Scenarios**:

1. **Given** первая загрузка страницы, **When** данные ещё не пришли, **Then** на вкладке «Все» виден активный чип «Все», в области сетки — индикатор загрузки; пустое состояние и ошибка не мелькают.
2. **Given** выбран тег, **When** идёт запрос, **Then** выбранный чип остаётся активным, чипы и «Ещё подборки» недоступны, а сообщение загрузки называет выбранный тег.
3. **Given** запрос завершился успешно, **When** пришли подборки, **Then** сетка показывает карточки, статус подтверждает применение фильтра, индикатор загрузки и пустое состояние скрыты.
4. **Given** по тегу нет подборок, **When** запрос завершился успешно, **Then** показывается пустое состояние с названием тега и кнопкой сброса; это не ошибка.
5. **Given** нет ни одной подборки без фильтра, **When** загрузка завершилась, **Then** показывается пустое состояние и действие «Обновить».
6. **Given** первая загрузка упала, **When** ошибка получена, **Then** показываются сообщение об ошибке и кнопка «Повторить»; чип «Все» остаётся активным.
7. **Given** запрос по тегу упал, **When** ошибка получена, **Then** показываются сообщение с названием тега и кнопка «Повторить»; выбранный чип остаётся активным, а чипы снова доступны для смены фильтра или сброса.
8. **Given** показана ошибка, **When** пользователь нажимает «Повторить», **Then** снова показывается загрузка, кнопка повторного запроса недоступна, а после ответа отображается успех, пустота или ошибка.
9. **Given** любое состояние ошибки, **When** сообщение показано, **Then** пользователь не видит HTTP-коды, имена внутренних полей и другие технические детали.

### User Story 4 - Вкладка «Избранное» и возврат на «Все» (Priority: P2)

Фильтр относится только к вкладке «Все». На «Избранном» пользователь видит все избранные подборки и не отвлекается на чипы.

**Why this priority**: важно не сломать существующее избранное и не создать иллюзию, что фильтр действует на него.

**Independent Test**: выбрать тег, перейти в «Избранное», проверить полный список избранного и вернуться на «Все»; фильтр должен восстановиться.

**Acceptance Scenarios**:

1. **Given** на «Все» выбран тег, **When** пользователь переходит на «Избранное», **Then** чипы скрыты, показываются все избранные подборки, счётчик избранного не меняется, фильтр к избранному не применяется.
2. **Given** пользователь на «Избранном», **When** он возвращается на «Все», **Then** ранее выбранный тег снова активен и подборки загружаются с этим фильтром.
3. **Given** выбранный тег исчез из доступных, **When** пользователь возвращается на «Все» или обновляет список, **Then** фильтр сбрасывается на «Все», показываются все подборки и появляется короткое уведомление о сбросе.
4. **Given** запрос фильтра ещё выполняется, **When** пользователь переходит на «Избранное», **Then** поздний ответ не заменяет содержимое «Избранного»; при возврате на «Все» фильтр загружается заново.
5. **Given** пустое или ошибочное состояние «Избранного», **When** вкладка открыта, **Then** чипы фильтра не показываются, а существующее поведение загрузки, пустоты и ошибки избранного сохраняется.
6. **Given** карточка в отфильтрованном списке, **When** пользователь добавляет её в избранное или открывает корзину, **Then** действие работает, фильтр не сбрасывается, счётчик избранного обновляется.

---

### User Story 5 - Клавиатура и мобильная прокрутка чипов (Priority: P2)

Пользователь без мыши и пользователь на узком экране могут добраться до любого тега, выбрать его и сбросить фильтр.

**Why this priority**: чипы — основной орган управления фильтром; если до них не добраться, фича недоступна.

**Independent Test**: пройти все чипы только клавиатурой; отдельно открыть страницу на ширине 320 px и проверить прокрутку строки чипов.

**Acceptance Scenarios**:

1. **Given** клавиатурный фокус на вкладках, **When** пользователь нажимает Tab, **Then** фокус последовательно проходит по «Все» и тегам в визуальном порядке; Shift+Tab возвращает назад.
2. **Given** фокус на чипе, **When** пользователь нажимает Enter или Space, **Then** чип активируется так же, как при нажатии мышью.
3. **Given** фокус на чипе, **When** он видим, **Then** у чипа есть заметная рамка фокуса, а активный чип сообщает нажатое состояние через `aria-pressed`.
4. **Given** идёт загрузка, **When** пользователь перемещает фокус по чипам, **Then** чипы остаются в порядке фокуса, но не запускают запрос и объявляются недоступными.
5. **Given** пустой результат, **When** пользователь нажимает кнопку сброса, **Then** фокус оказывается на чипе «Все».
6. **Given** ширина экрана 320 px, **When** тегов больше, чем помещается, **Then** строка чипов остаётся одной строкой с горизонтальной прокруткой, страница не получает горизонтальную прокрутку, а последний чип достижим.
7. **Given** чип получил клавиатурный фокус, **When** он находится за пределами видимой части строки, **Then** строка прокручивается и показывает этот чип.
8. **Given** пользователь прокручивает строку чипов пальцем, **When** прокрутка заканчивается, **Then** выбранный тег не меняется случайно.

---

### Edge Cases

- Сервер вернул пустой список тегов: показывается только «Все», фильтрация недоступна, подборки отображаются без фильтра.
- Выбранный тег пропал из списка доступных после успешной загрузки: фильтр сбрасывается на «Все» с коротким уведомлением.
- Тег есть в списке, но по нему нет подборок: это пустой результат, а не ошибка; доступен сброс.
- Подходящих подборок больше 12: интерфейс показывает не более 12 карточек.
- Ошибка при первой загрузке: доступны только «Все» и повтор; после успешного повтора появляются теги.
- Переключение вкладок во время запроса: поздний ответ не смешивает отфильтрованные подборки с избранным.
- Быстрые повторные нажатия по чипам: пока идёт запрос, второй запрос не запускается.
- Нажатие «Ещё подборки» при активном фильтре: загружается новая случайная выборка внутри выбранного тега, фильтр сохраняется.
- Изменение избранного или открытие корзины на отфильтрованной карточке: фильтр и состояние избранного не ломаются.
- Очень длинное название тега: чип остаётся читаемым, строка чипов прокручивается, текст не обрезается до нечитаемого состояния.
- Тег в другом регистре: интерфейс не создаёт второй чип; активным считается чип, соответствующий каноническому значению, которое вернул сервер.

## Requirements *(mandatory)*

### Functional Requirements

**Строка чипов и выбор**

- **FR-001**: На вкладке «Все» над сеткой MUST отображаться одна строка чипов: первым «Все», затем все доступные теги из последнего успешного ответа сервера в порядке сервера.
- **FR-002**: Одновременно MUST быть активен только один чип: «Все» — когда фильтр не применён, тег — когда применён фильтр по этому тегу.
- **FR-003**: Активный чип MUST быть визуально отличим и MUST иметь `aria-pressed="true"`; неактивные чипы — `aria-pressed="false"`.
- **FR-004**: Активация тега MUST выбирать этот тег, переводить интерфейс в состояние загрузки и запускать ровно один запрос; чипы и «Ещё подборки» на время запроса MUST быть недоступны.
- **FR-005**: Во время загрузки в области сетки MUST показываться индикатор загрузки вместо карточек; пустое состояние и ошибка в это время MUST NOT показываться.
- **FR-006**: После успешной загрузки сетка MUST показывать только подборки с выбранным тегом, не более 12 карточек; если подходящих меньше — столько, сколько есть.
- **FR-007**: После успешной загрузки статус MUST подтверждать, что показаны подборки по выбранному тегу или все подборки.
- **FR-008**: Если по выбранному тегу подборок нет, MUST показываться пустое состояние с названием тега и кнопкой «Сбросить фильтр»; это состояние MUST NOT считаться ошибкой.
- **FR-009**: Если подборок нет без фильтра, MUST показываться пустое состояние с кнопкой «Обновить», которая повторяет загрузку всех подборок.

**Сброс и повтор**

- **FR-010**: Повторная активация активного тега MUST снимать фильтр, делать активным «Все» и загружать все подборки.
- **FR-011**: Активация «Все» MUST снимать любой фильтр и загружать все подборки.
- **FR-012**: Кнопка «Сбросить фильтр» в пустом состоянии MUST снимать фильтр, активировать «Все», загружать все подборки и переводить фокус на чип «Все».
- **FR-013**: При ошибке первой загрузки MUST показываться сообщение об ошибке и кнопка «Повторить»; чип «Все» остаётся активным, теги могут отсутствовать.
- **FR-014**: При ошибке загрузки по тегу MUST показываться сообщение с названием тега и кнопка «Повторить»; выбранный чип остаётся активным, а чипы снова доступны для смены фильтра или сброса.
- **FR-015**: Нажатие «Повторить» MUST повторять последний неуспешный запрос с тем же тегом (или без тега, если фильтр не был выбран), переводить интерфейс в загрузку и блокировать повторное нажатие до ответа.
- **FR-016**: Если повтор снова завершается ошибкой, MUST снова показываться сообщение и доступная кнопка «Повторить».
- **FR-017**: Сообщения об ошибке MUST быть понятны пользователю и MUST NOT содержать HTTP-коды, имена внутренних полей и другие технические детали.
- **FR-018**: Пока идёт запрос, повторная активация чипов MUST NOT запускать второй запрос.

**Состояния и объявления**

- **FR-019**: Загрузка, успех, пустой результат и ошибка MUST объявляться программе экранного доступа через живой регион.
- **FR-020**: Индикатор загрузки, успех, пустота и ошибка MUST быть различимы по тексту, а не только по цвету.
- **FR-021**: После успешной загрузки MUST NOT оставаться видимыми индикатор загрузки, сообщение об ошибке или пустое состояние, не относящееся к текущему результату.

**Вкладка «Избранное»**

- **FR-022**: На вкладке «Избранное» чипы фильтра MUST быть скрыты, а фильтр MUST NOT применяться: показываются все избранные подборки.
- **FR-023**: Счётчик избранного MUST показывать общее количество избранных подборок независимо от фильтра.
- **FR-024**: Выбранный на «Все» тег MUST сохраняться при переходе на «Избранное» и восстанавливаться при возврате на «Все»; подборки при возврате MUST загружаться с этим фильтром.
- **FR-025**: Если сохранённый тег отсутствует в актуальном списке тегов, при возврате на «Все» или после обновления фильтр MUST сбрасываться на «Все», показываться все подборки и короткое уведомление о сбросе.
- **FR-026**: Ответ, запрошенный для вкладки, которая уже не активна, MUST NOT изменять содержимое текущей вкладки; при возврате на «Все» данные MUST загружаться заново с сохранённым фильтром.
- **FR-027**: Существующие состояния «Избранного» (загрузка, пустота, ошибка) MUST сохраняться; чипы фильтра к ним не добавляются.

**Обновление и совместимость**

- **FR-028**: «Ещё подборки» при активном фильтре MUST загружать новую случайную выборку внутри выбранного тега и сохранять фильтр; без фильтра — загружать все подборки.
- **FR-029**: «Ещё подборки» MUST быть недоступна во время любой загрузки.
- **FR-030**: Добавление в избранное и открытие корзины на отфильтрованных карточках MUST работать как раньше и MUST NOT сбрасывать фильтр.
- **FR-031**: Интерфейс MUST отображать теги в порядке сервера и MUST NOT сортировать их самостоятельно.
- **FR-032**: Если сервер вернул пустой список тегов, MUST показываться только «Все», а подборки — без фильтра.
- **FR-033**: Интерфейс MUST NOT нормализовать регистр тегов самостоятельно; активным считается чип, соответствующий каноническому значению, которое вернул сервер.
- **FR-034**: Интерфейс MUST показывать не более 12 карточек; если сервер вернул больше, лишние MUST NOT отображаться.
- **FR-035**: Весь текст интерфейса фильтра MUST быть на русском языке.

**Клавиатура и доступность**

- **FR-036**: Все чипы MUST быть достижимы клавишей Tab в визуальном порядке; Shift+Tab MUST возвращать фокус назад.
- **FR-037**: Enter и Space на чипе MUST активировать его так же, как нажатие мышью.
- **FR-038**: Фокус MUST быть всегда видимым; активный чип MUST иметь `aria-pressed`, а группа чипов — доступное имя, например «Фильтр по тегам».
- **FR-039**: Во время загрузки чипы MUST оставаться в порядке фокуса, но MUST игнорировать активацию и объявляться недоступными; фокус MUST NOT теряться из-за блокировки.
- **FR-040**: Если активированный элемент исчезает (кнопка сброса в пустом состоянии или кнопка повтора после успеха), фокус MUST переходить на «Все» или на активный чип, чтобы пользователь не потерял место.
- **FR-041**: Контраст текста, границ, активного и фокусного состояний MUST соответствовать уровню WCAG AA.
- **FR-042**: Активное состояние MUST отличаться от неактивного не только цветом (например, рамкой, толщиной или дополнительным признаком).

**Мобильная строка чипов**

- **FR-043**: На узком экране чипы MUST располагаться одной строкой с горизонтальной прокруткой и MUST NOT переноситься на несколько строк.
- **FR-044**: Горизонтальная прокрутка строки чипов MUST NOT вызывать горизонтальную прокрутку всей страницы.
- **FR-045**: Последний чип MUST быть достижим прокруткой, а «Все» MUST оставаться первым элементом строки.
- **FR-046**: При получении клавиатурного фокуса чип MUST прокручиваться в видимую область строки.
- **FR-047**: Область нажатия каждого чипа MUST быть не меньше 44×44 CSS-пикселей.
- **FR-048**: Прокрутка строки чипов MUST NOT менять выбранный тег.

**Границы**

- **FR-049**: Фича MUST NOT добавлять выбор нескольких тегов, поиск по тексту, сортировку, счётчики подборок на чипах или сохранение фильтра в URL.
- **FR-050**: Фича MUST NOT менять поведение корзины и избранного, кроме скрытия чипов на вкладке «Избранное».

## Acceptance Criteria

Проверяемые критерии приёмки:

- **AC-01**: На вкладке «Все» видны «Все» и все доступные теги; «Все» стоит первым.
- **AC-02**: Активация тега показывает только подборки с этим тегом; активен ровно один чип.
- **AC-03**: Повторная активация активного тега снимает фильтр и показывает все подборки.
- **AC-04**: Активация «Все» снимает фильтр из любого состояния, кроме загрузки.
- **AC-05**: При активном фильтре показывается не более 12 карточек; при меньшем числе — ровно столько, сколько пришло.
- **AC-06**: Пустой результат по тегу показывает название тега и кнопку сброса, а не ошибку.
- **AC-07**: Пустой результат без фильтра показывает кнопку «Обновить».
- **AC-08**: Во время загрузки видны индикатор загрузки и сообщение; чипы и «Ещё подборки» недоступны; повторные нажатия не создают второй запрос.
- **AC-09**: Успешная загрузка убирает индикатор загрузки, пустое состояние и ошибку, оставляя только карточки и подтверждающий статус.
- **AC-10**: Ошибка первой загрузки показывает сообщение и «Повторить»; повтор запускает загрузку.
- **AC-11**: Ошибка фильтра показывает сообщение с названием тега и «Повторить»; чипы остаются доступными.
- **AC-12**: Повтор после ошибки загружает тот же фильтр; при повторной ошибке снова доступен повтор.
- **AC-13**: На «Избранном» чипы скрыты, показываются все избранные подборки, счётчик не меняется.
- **AC-14**: Возврат на «Все» восстанавливает выбранный тег и загружает подборки с ним.
- **AC-15**: Если тег исчез, возврат на «Все» сбрасывает фильтр и показывает уведомление.
- **AC-16**: Поздний ответ запроса, начатого на другой вкладке, не меняет содержимое текущей вкладки.
- **AC-17**: Все чипы достигаются Tab; Enter и Space активируют; фокус видим; активный чип имеет `aria-pressed="true"`.
- **AC-18**: Во время загрузки чипы не теряют фокус и не активируются.
- **AC-19**: После сброса через пустое состояние фокус находится на «Все».
- **AC-20**: На ширине 320 px строка чипов прокручивается горизонтально, страница — нет; последний чип достижим.
- **AC-21**: Сфокусированный за пределами видимости чип прокручивается в видимую область.
- **AC-22**: Активное, фокусное и неактивное состояния различимы не только цветом и проходят проверку контраста WCAG AA.
- **AC-23**: Добавление в избранное и открытие корзины работают до и после фильтра; фильтр при этом не сбрасывается.
- **AC-24**: «Ещё подборки» при активном фильтре сохраняет тег и загружает новую выборку внутри него.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Пользователь применяет фильтр одним действием и видит только подборки выбранного тега; все сценарии AC-01–AC-24 проходят без исключений.
- **SC-002**: Сброс фильтра доступен одним действием из любого состояния, где он применён, включая пустой результат и ошибку.
- **SC-003**: В сетке никогда не больше 12 карточек; при меньшем числе подходящих отображается точное количество без пустых мест.
- **SC-004**: Каждое из состояний — загрузка, успех, пустота, ошибка — имеет текст и отличимо без опоры только на цвет.
- **SC-005**: Пользователь без мыши может добраться до каждого чипа, сброса, повтора и вкладок, активировать их и всегда видеть фокус.
- **SC-006**: На ширине 320 px строка чипов прокручивается до последнего элемента, а ширина страницы не превышает ширину экрана.
- **SC-007**: При восстановлении сервера кнопка «Повторить» возвращает интерфейс в состояние успеха или пустоты без перезагрузки страницы.
- **SC-008**: Переключение вкладок не смешивает отфильтрованные подборки с избранным и не меняет счётчик избранного.
- **SC-009**: Добавление в избранное и открытие корзины работают до и после фильтрации без регрессий.
- **SC-010**: Программа экранного доступа объявляет загрузку, результат, пустоту и ошибку, а активный чип сообщает нажатое состояние.

## Assumptions

- Список тегов приходит с сервера при успешной загрузке подборок; интерфейс не хранит собственный список тегов и не придумывает значения.
- Фильтр применяется только к вкладке «Все»; на «Избранном» он не действует, а чипы скрыты.
- Выбранный тег сохраняется в памяти при переходе на «Избранное» и восстанавливается при возврате на «Все». Это осознанный выбор по умолчанию; если команда логики решит иначе, поведение возврата нужно синхронизировать со спекой.
- Если сохранённый тег исчез из списка доступных, безопасный дефолт — сброс на «Все» с коротким уведомлением, а не пустой экран с несуществующим чипом.
- Сервер отдаёт не более 12 подборок после фильтрации; если подходящих меньше, возвращает меньше; ноль — валидный пустой результат, а не ошибка.
- Во время загрузки сетка показывает состояние загрузки вместо прежних карточек; прежние карточки не возвращаются автоматически после ошибки, но доступен повтор.
- Для пустого результата без активного фильтра используется действие «Обновить», потому что сбрасывать нечего; кнопка сброса предусмотрена для пустого результата по тегу.
- «Ещё подборки» уважает активный фильтр и загружает новую случайную выборку внутри выбранного тега.
- Порядок карточек и случайность выборки определяет сервер; интерфейс не сортирует карточки и теги.
- Регистр тегов нормализует сервер; интерфейс только отображает полученные значения и выделяет каноническое активное значение.
- Счётчики подборок на чипах, выбор нескольких тегов, поиск, сортировка и сохранение фильтра в URL не входят в фичу.
- Существующие состояния «Избранного» и корзины не перерабатываются; фича только скрывает чипы на «Избранном» и не вмешивается в их загрузку.
- Сообщения об ошибках можно показывать без технических деталей; конкретные формулировки могут меняться, если сохраняется смысл и доступность.
- Все интерактивные элементы фильтра рассчитаны на русскоязычный интерфейс и нажатие пальцем на мобильном устройстве.

## Out of Scope

- Изменение серверного контракта, выбор адреса запроса, имени параметра или формата ответа.
- Выбор нескольких тегов одновременно, поиск по тексту, сортировка.
- Сохранение фильтра в URL и шаринг ссылки с фильтром.
- Счётчики подборок рядом с чипами.
- Изменение схемы данных, логики корзины и логики избранного.
- Новые визуальные темы, переработка карточек или вкладок сверх скрытия чипов на «Избранном».

## For the Logic Team to Confirm

1. Список тегов приходит вместе с подборками и содержит только доступные теги активного пула, без дублей и пустых значений; порядок тегов стабилен и используется интерфейсом как есть.
2. Каноническое написание тега и правило сравнения без учёта регистра; интерфейс должен получить каноническое значение, чтобы выделить правильный чип.
3. Поведение для неизвестного или устаревшего тега: успешный пустой результат, а не ошибка; что при этом считается активным тегом и как интерфейсу показать название тега в пустом состоянии.
4. Входят ли в список тегов теги без подборок; если да, выбор такого тега должен давать пустое состояние с кнопкой сброса.
5. Лимит 12 применяется после фильтрации; при меньшем числе возвращается меньше; ноль подборок — успешный ответ.
6. Ответ с отфильтрованными подборками по-прежнему содержит актуальный список избранного, чтобы сердца на карточках не ломались.
7. «Ещё подборки» с активным тегом возвращает новую случайную выборку внутри этого тега, а не игнорирует фильтр.
8. Что происходит, если выбранный тег исчезает из пула между запросами: сервер сообщает об этом так, чтобы интерфейс мог сбросить фильтр и показать уведомление.
9. Ошибки сервера отдают понятное сообщение, пригодное для показа пользователю, либо интерфейсу разрешено показывать собственный общий текст без технических деталей.
10. Избранное и корзина не зависят от фильтра и продолжают работать при активном фильтре и при возврате с «Избранного».
