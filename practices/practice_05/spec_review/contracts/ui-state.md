# Контракт UI: строка чипов и состояния фильтра

**Статус**: согласован с `contract.md` и итоговой `spec.md`.

**Область**: только вкладка «Все» и общие состояния загрузки/пустоты/
ошибки. Корзина и избранное сохраняют существующее поведение.

## 1. DOM-контракт

| Элемент | Назначение |
| --- | --- |
| `#tag-bar` | контейнер строки чипов; `role="group"`, доступное имя «Фильтр по тегам» |
| `.chip` | кнопка чипа; `type="button"`, `data-tag`, `aria-pressed` |
| `#grid` | сетка карточек без `aria-live`; в загрузке содержит индикатор вместо карточек |
| `#feedback` | единственная панель пустоты/ошибки; скрыта в успехе и загрузке; `#empty` удаляется |
| `#feedback-text` | пользовательский текст состояния |
| `#feedback-action` | кнопка действия: «Сбросить фильтр», «Обновить» или «Повторить»; может быть скрыта |
| `#status` | `role="status"`, живой регион для загрузки/успеха/пустоты/ошибки |
| `#notice` | `role="status"`, живой регион для автосброса устаревшего тега |
| `#refresh` | «Ещё подборки»; блокируется на время загрузки |
| `#fav-count` | счётчик избранного; не зависит от фильтра |

Чипы создаются из `state.tags` в порядке сервера. Первый чип — «Все» с
`data-tag=""`. UI не сортирует, не дедуплицирует и не меняет регистр
тегов.

## 2. Состояние

```text
state = {
  mode: "all" | "favorites",
  collections: Collection[],
  favorites: Set<string>,
  tags: string[],
  activeTag: string,          // "" = Все
  loading: boolean,
  error: null | { message: string, status: number, tag: string },
  requestSeq: number,
  lastRequestTag: string,
  noticeTimer: number | null
}
```

- `activeTag` хранится в памяти и не пишется в URL.
- При переходе на «Избранное» `activeTag` не сбрасывается.
- При возврате на «Все» подборки загружаются заново с `activeTag`.
- `lastRequestTag` нужен кнопке «Повторить».
- `favorites` синхронизируется из `favorites` в `/api/collections` или по
  id из `collections` в `/api/favorites`; endpoint не меняется.
- `requestMode` — локальная копия `mode` на момент старта запроса; она
  не хранится в URL и нужна для отбрасывания поздних ответов.

## 3. Действия и переходы

| Действие | Условие | Результат |
| --- | --- | --- |
| Первый вход | — | `loading=true`, запрос без тега, чип «Все» активен |
| Клик/Enter/Space по тегу | не загрузка, тег не активен | `activeTag=тег`, `loading=true`, один запрос |
| Клик/Enter/Space по активному тегу | не загрузка | `activeTag=""`, загрузка всех |
| Клик по «Все» | не загрузка | `activeTag=""`, загрузка всех |
| «Сбросить фильтр» в пустоте | не загрузка | `activeTag=""`, загрузка всех, фокус на «Все» |
| «Обновить» в пустоте без фильтра | не загрузка | запрос без тега |
| «Повторить» после ошибки `500` | не загрузка | запрос с `lastRequestTag` |
| «Сбросить фильтр» после ошибки `400` | не загрузка | `activeTag=""`, загрузка всех, фокус на «Все» |
| «Ещё подборки» | не загрузка, `mode="all"` | запрос с текущим `activeTag` |
| «Ещё подборки» | не загрузка, `mode="favorites"` | текущий `loadCollections`, `activeTag`/`tags` не меняются |
| Переход на «Избранное» | — | `mode="favorites"`, чипы скрыты, запрос `/api/favorites` |
| Возврат на «Все» | — | `mode="all"`, запрос с сохранённым `activeTag` |
| Любая активация во время загрузки | `loading=true` | игнорируется, второй запрос не стартует |
| Успех, `mode="all"` и `activeTag` отсутствует в `tags` | — | сброс на «Все», уведомление, запрос без тега |
| Поздний ответ | `requestSeq` не совпал или `requestMode != mode` | ответ отбрасывается; `loadFavorites` дополнительно требует `mode="favorites"` |

### Автосброс устаревшего тега

После успешного ответа:

1. При `mode="all"` если `active_tag` непустой и отсутствует в `tags`,
   тег считается исчезнувшим.
2. `activeTag` сбрасывается в `""`.
3. Показывается `#notice` с текстом «Тег больше недоступен, фильтр
   сброшен» примерно на 5 секунд, без модального окна.
4. Загружаются все подборки.
5. Пустое состояние с именем исчезнувшего тега не показывается.

## 4. Отрисовка

### Чипы

- Показываются только при `mode="all"`.
- «Все» всегда первый, затем `state.tags`.
- У активного чипа `aria-pressed="true"`, у всех остальных —
  `aria-pressed="false"`.
- Активный чип: заливка, рамка/внутренняя тень и жирное начертание;
  отличие не только цветом.
- `loading=true`: `aria-disabled="true"` у всех чипов, активация
  игнорируется, но чипы остаются в Tab-порядке и не теряют фокус.
- На «Избранном» `#tag-bar` скрыт полностью, включая пустое и ошибочное
  состояние избранного.

### Сетка и панель состояния

| Состояние | `#grid` | `#feedback` | `#status` |
| --- | --- | --- | --- |
| Загрузка | индикатор загрузки, `aria-busy="true"` | скрыта | «Загружаем подборки…» или «Загружаем подборки по тегу «X»…» |
| Успех без фильтра | карточки | скрыта | «Показаны все подборки» |
| Успех с фильтром | карточки | скрыта | «Показаны подборки по тегу «X»» |
| Пусто с фильтром | пусто | текст «По тегу «X» ничего не найдено» + «Сбросить фильтр» | «По тегу «X» ничего не найдено» |
| Пусто без фильтра | пусто | «Подборок пока нет» + «Обновить» | «Подборок пока нет» |
| Ошибка `500` без фильтра | пусто | «Не удалось загрузить подборки. Попробуйте ещё раз.» + «Повторить» | то же |
| Ошибка `500` с фильтром | пусто | «Не удалось загрузить подборки по тегу «X». Попробуйте ещё раз.» + «Повторить» | то же |
| Ошибка `400` | пусто | «Не удалось применить фильтр.» + «Сбросить фильтр» | то же |
| Избранное | карточки избранного | существующая пустота/ошибка | существующие тексты |

Тексты ошибок не содержат HTTP-кодов, имён полей и технических
деталей. Поле `error` из API не выводится как есть. Для `400`
показывается действие сброса, для `500` — «Повторить».

## 5. Фокус и доступность

- Tab/Shift+Tab проходят по «Все» и тегам в визуальном порядке.
- Enter и Space на чипе работают как клик.
- У всех интерактивных элементов видимый `:focus-visible`.
- После «Сбросить фильтр» фокус переходит на чип «Все».
- Если кнопка, на которой был фокус, исчезает после успеха (например,
  «Повторить»), фокус переходит на активный чип или «Все».
- Во время загрузки фокус не теряется из-за `disabled`; используется
  `aria-disabled` и программная проверка.
- Загрузка, успех, пустота и ошибка объявляются через единственный
  `#status` (`role="status"`); у `#grid` нет `aria-live`. Уведомление об
  исчезнувшем теге — через `#notice` (`role="status"`).
- Чип активен по `aria-pressed`; группа имеет доступное имя.
- Область нажатия чипа не меньше 44×44 CSS px.

## 6. Мобильная строка

- `#tag-bar` — одна строка: `display:flex`, `flex-wrap:nowrap`,
  `overflow-x:auto`, `min-width:0`.
- Страница не получает горизонтальную прокрутку.
- Последний чип достижим прокруткой; «Все» остаётся первым.
- При клавиатурном фокусе чип прокручивается в видимую область
  (`scrollIntoView({block:"nearest", inline:"nearest"})`).
- Прокрутка/свайп по строке не меняет `activeTag`.
- Длинный текст чипа не обрезается до нечитаемого состояния; строка
  прокручивается.

## 7. Границы

- Фильтр не действует на «Избранное» и не меняет счётчик.
- Добавление в избранное и корзина на отфильтрованной карточке работают
  без сброса фильтра.
- Выбор нескольких тегов, поиск, сортировка, счётчики на чипах и
  сохранение фильтра в URL не появляются.
