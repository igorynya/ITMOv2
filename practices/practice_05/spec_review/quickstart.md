# Quickstart: проверка фильтра подборок по тегу

**Дата**: 2026-10-23

## 1. Подготовка

```sh
cd practices/practice_04/collections
go test ./...
go vet ./...
```

Ожидание: все тесты проходят, `go vet` без замечаний. Новые зависимости
не нужны.

Запуск:

```sh
make run
```

Откройте `http://localhost:8080`. Первая генерация может занять около
минуты и требует доступ к MCP; если сети нет, сервис использует
последнее сохранённое поколение из `data/collections.db`.

## 2. Автоматические проверки

| Команда | Что проверяет |
| --- | --- |
| `go test ./internal/domain` | обрезка, канонизация, регистр, 64 символа, пустые теги |
| `go test ./internal/store` | активный пул только текущего поколения |
| `go test ./internal/httpapi` | параметр `tag`, коды `200/400/500`, `tags`, `active_tag`, лимит, избранное, один вызов `ActivePool` |
| `go test ./...` | все пакеты |
| `go vet ./...` | статические ошибки |

## 3. Проверки API через curl

`COLLECTIONS_PER_PAGE` по умолчанию 12. Для читаемого вывода используйте
`python3 -m json.tool`.

### Без фильтра

```sh
curl -s 'http://localhost:8080/api/collections' | python3 -m json.tool
```

Ожидание:

- `200`;
- `active_tag` — `""`;
- `tags` — полный список доступных тегов;
- `collections` — до 12 активных подборок;
- `favorites` — полный список избранного.

### Известный тег

```sh
curl -s --get --data-urlencode 'tag=ужин' \
  'http://localhost:8080/api/collections' | python3 -m json.tool
```

Ожидание:

- все `collections` содержат тег «ужин»;
- `active_tag` — каноническое написание;
- `tags` не сужен до «ужина».

### Другой регистр и пробелы

```sh
curl -s --get --data-urlencode 'tag=УЖИН' \
  'http://localhost:8080/api/collections' | python3 -m json.tool

curl -s --get --data-urlencode 'tag=  ужин  ' \
  'http://localhost:8080/api/collections' | python3 -m json.tool
```

Ожидание: тот же набор подборок и тот же `active_tag`, что и для
«ужин».

### Пустой тег

```sh
curl -s 'http://localhost:8080/api/collections?tag=' \
  | python3 -m json.tool
```

Ожидание: как без фильтра, `active_tag: ""`.

### Неизвестный тег

```sh
curl -s --get --data-urlencode 'tag=нет-такого' \
  'http://localhost:8080/api/collections' | python3 -m json.tool
```

Ожидание: `200`, `collections: []`, `tags` и `favorites` полные,
`active_tag` — `"нет-такого"`.

### Слишком длинный тег

```sh
TAG65=$(python3 -c 'print("я" * 65)')
curl -s -o /dev/null -w '%{http_code}\n' \
  --get --data-urlencode "tag=$TAG65" \
  'http://localhost:8080/api/collections'
```

Ожидание: `400` и JSON с полем `error`.

Для ровно 64 символов:

```sh
TAG64=$(python3 -c 'print("я" * 64)')
curl -s -o /dev/null -w '%{http_code}\n' \
  --get --data-urlencode "tag=$TAG64" \
  'http://localhost:8080/api/collections'
```

Ожидание: `200` (скорее всего, пустой результат, если такого тега
нет).

### Повторённый параметр

```sh
curl -s -o /dev/null -w '%{http_code}\n' --get \
  --data-urlencode 'tag=ужин' \
  --data-urlencode 'tag=обед' \
  'http://localhost:8080/api/collections'
```

Ожидание: `400` и поле `error`.

### Битый URL и UTF-8

```sh
curl -s -o /dev/null -w '%{http_code}\n' \
  'http://localhost:8080/api/collections?tag=%zz'
curl -s -o /dev/null -w '%{http_code}\n' \
  'http://localhost:8080/api/collections?tag=%FF'
```

Ожидание: оба запроса дают `400`, JSON с полем `error`; store не
вызывается.

### Избранное не фильтруется

Сначала добавьте любую подборку в избранное в UI, затем:

```sh
curl -s 'http://localhost:8080/api/collections?tag=ужин' \
  | python3 -m json.tool
curl -s 'http://localhost:8080/api/collections' \
  | python3 -m json.tool
```

Ожидание: `favorites` в обоих ответах одинаковый.

## 4. Ручные проверки UI

### 4.1. Основной сценарий

1. Откройте вкладку «Все».
2. Убедитесь, что над сеткой есть одна строка: «Все» и теги.
3. Нажмите тег «ужин».
4. Во время загрузки чипы и «Ещё подборки» недоступны, в области сетки
   индикатор, в статусе назван тег.
5. После успеха в сетке только подборки с «ужин», активен ровно один
   чип, карточек не больше значения `COLLECTIONS_PER_PAGE`.
6. Нажмите «Ещё подборки» — новая выборка внутри тега, фильтр
   сохраняется.
7. Повторно нажмите активный чип — фильтр снят, активен «Все».
8. Выберите тег снова и нажмите «Все» — фильтр снят.

### 4.2. Пустота

Нужен тег, по которому нет активных подборок. Если в текущих данных
такого нет, проверьте сценарий на тестовом стенде с ограниченным
поколением.

1. Выберите тег без результатов.
2. Ожидание: пустое состояние с названием тега и кнопкой «Сбросить
   фильтр»; это не ошибка.
3. Нажмите «Сбросить фильтр»: активен «Все», загружены все подборки,
   фокус на чипе «Все».

### 4.3. Ошибка и повтор

1. Откройте DevTools → Network → Offline (или остановите сервер после
   загрузки страницы).
2. Выберите тег.
3. Ожидание: сообщение об ошибке с названием тега, кнопка «Повторить»,
   чипы снова доступны, выбранный чип остаётся активным.
4. Включите сеть и нажмите «Повторить».
5. Ожидание: загрузка, затем успех или пустота; повторная ошибка снова
   показывает «Повторить».
6. Убедитесь, что в сообщении нет HTTP-кодов и имён полей.
7. Отдельно проверьте `400`: в DevTools перехватите запрос и верните
   ответ с ошибкой валидации. Ожидание: сообщение о невозможности
   применить фильтр и «Сбросить фильтр», без «Повторить»; после сброса
   загружаются все подборки.

### 4.4. Избранное

1. Выберите тег на «Все».
2. Перейдите на «Избранное».
3. Ожидание: чипы скрыты, показаны все избранные подборки, счётчик не
   изменился.
4. Вернитесь на «Все».
5. Ожидание: выбранный тег снова активен, подборки загружены с
   фильтром.
6. Снова перейдите на «Избранное», нажмите «Ещё подборки» и вернитесь
   на «Все».
7. Ожидание: сохранённый тег не потерян, фильтр восстановлен.

### 4.5. Клавиатура

1. Поставьте фокус на вкладки и нажимайте Tab.
2. Ожидание: фокус проходит по «Все» и тегам в визуальном порядке;
   Shift+Tab возвращает назад.
3. Нажмите Enter и Space на чипе.
4. Ожидание: чип активируется как мышью.
5. Ожидание: у чипа заметная рамка фокуса, у активного чипа
   `aria-pressed="true"`, у остальных — `aria-pressed="false"`.
6. Во время загрузки подвигайте фокус по чипам.
7. Ожидание: чипы остаются в Tab-порядке, но не запускают запрос и
   объявляются недоступными.

### 4.6. Мобильная ширина

1. Откройте DevTools → Responsive, ширина 320 px.
2. Ожидание: строка чипов остаётся одной строкой с горизонтальной
   прокруткой; страница не получает горизонтальную прокрутку.
3. Прокрутите строку до последнего чипа.
4. Ожидание: последний чип достижим, «Все» остаётся первым.
5. Сфокусируйте чип за пределами видимой части строки клавиатурой.
6. Ожидание: строка прокручивается и показывает чип.
7. Сделайте свайп по строке.
8. Ожидание: выбранный тег не меняется случайно.

### 4.7. Карточки, избранное и корзина

1. При активном фильтре добавьте карточку в избранное.
2. Ожидание: счётчик избранного обновился, фильтр не сбросился.
3. Откройте корзину с отфильтрованной карточки.
4. Ожидание: ссылка создаётся как раньше, фильтр не ломается.
5. Перейдите на «Избранное» и обратно.
6. Ожидание: фильтр восстановлен, избранное не потеряно.

### 4.8. Пустой список тегов

1. Сделайте так, чтобы активный пул не содержал ни одного пригодного
   тега, либо подмените `tags` в ответе на `[]`.
2. Ожидание: в строке чипов остаётся только «Все», фильтр не
   применяется, подборки показываются без фильтра.

### 4.9. Автосброс устаревшего тега

Нужна смена поколения данных, в котором выбранный тег исчез. В учебном
окружении проще проверить на тестовом стенде или через подмену ответа
API.

1. Выберите тег.
2. Сделайте так, чтобы в новом ответе `tags` больше не содержал этот
   тег, а `active_tag` был эхом запроса.
3. Ожидание: фильтр сбрасывается на «Все», загружаются все подборки,
   появляется сообщение «Тег больше недоступен, фильтр сброшен» примерно
   на 5 секунд; пустота с именем исчезнувшего тега не показывается.

## 5. Что считать регрессией

- В сетке больше `COLLECTIONS_PER_PAGE` карточек.
- При фильтре есть подборка без выбранного тега.
- `tags` сужен до результата фильтра.
- `collections`, `tags` или `favorites` приходят как `null`.
- Два чипа активны одновременно.
- У неактивного чипа отсутствует `aria-pressed="false"`.
- При `400` показывается «Повторить» вместо «Сбросить фильтр».
- При пустом `tags` появляется чип, которого нет в ответе.
- Повторное нажатие во время загрузки запускает второй запрос.
- Поздний ответ вкладки «Все» заменяет содержимое «Избранного».
- Избранное или корзина перестают работать при активном фильтре.
- Появляется горизонтальная прокрутка всей страницы на 320 px.
- Сообщение об ошибке содержит HTTP-код или имя поля.
