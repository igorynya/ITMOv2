# Few-shot

- Артефакт Практики 1: practices/practice_01/prompts.md (Master Prompt v2, список рисков)
- Что хотим улучшить: согласованность и воспроизводимость ответа.
  - Убрать противоречия и лишние полномочия из master prompt.
  - Зафиксировать формат результата: строго candidate -> evidence -> check с ссылками на файл и строки diff.
  - Снизить домыслы; не более 3 рисков, только факты из TRAINING_PR.diff.

## Примеры

### Хороший результат

candidate: Нет валидации входа в POST /api/reviews
evidence: app/api.py:35–38 — `create_review(payload: dict)` обращается к `payload["diff"]` без проверки наличия/типа
check: Отправить POST /api/reviews с `{}` → (AS IS) 500 из‑за KeyError; (TO BE) 422/400

### Плохой результат

— «Код можно улучшить. Добавьте обработку ошибок.» (нет файла/строк и проверки)
— Любые выводы, не подтверждённые diff или правилами кейса
— Больше трёх рисков или придуманные требования

## Запрос

Ниже формат и примеры. Следуй «Хорошему примеру», игнорируй «Плохой пример».

Контекст:
- Вход: @practices/practice_01/TRAINING_PR.diff
- Работай только по фактам diff. Не придумывай правила.

Формат результата (на русском): для каждого риска ровно три строки
```
candidate: <кратко суть>
evidence: <file:line-range> — <цитата или описание по diff>
check: <как воспроизвести и какой ожидаемый результат>
```

Хороший пример:
```
candidate: Нет валидации входа в POST /api/reviews
evidence: app/api.py:35–38 — create_review(payload: dict) обращается к payload["diff"] без проверки
check: POST /api/reviews с {} → (AS IS) 500; (TO BE) 422/400
```

Плохой пример:
```
Код можно улучшить. Добавьте тесты.
```

Задача:
- Найди не более 3 рисков в TRAINING_PR.diff.
- Для каждого верни candidate -> evidence -> check согласно формату.
- Укажи точные файлы и диапазоны строк как в diff.

## Что получили

Результат few-shot (сводка):
- Выделены 3 риска с точными ссылками: app/api.py:35–38; app/review_service.py:19–22.
- Для каждого риска оформлены candidate → evidence → check (AS IS vs TO BE).
- Синхронизировано с файлом [`few_shot/prompts.md`](prompts.md) — см. раздел Master Prompt (Few-shot) и список рисков.

- Как проверили: ответы содержат ссылки на file:line, каждый риск имеет evidence и check; домыслов нет; «Сравнение двух запусков» заполнено; make test для Практики 1 проходит.
