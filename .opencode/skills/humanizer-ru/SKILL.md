# Humanizer-ru

Область применения
- Редактирование уже существующего русского текста для более естественного звучания при неизменном содержании и степени уверенности.
- Не переводить, не генерировать новый контент, не переписывать аргументацию без явного запроса. Не применять к коду, конфига и данным.

Ограничения
- Сохранять: факты, числа, имена, даты, источники, отрицания, рамки, неопределённость («может», «возможно»), время, статус и атрибуцию.
- Не превращать возможность в уверенность и не добавлять отсутствующие детали. Если их нехватка мешает пониманию — спросить; иначе оставить обобщённость.
- Защищённый контент не менять: блоки кода, инлайн‑код, команды, пути, URL, цели ссылок, YAML и данные.
- Заголовки, якоря, порядок списков и таблицы сохранять, если пользователь явно не просил изменить структуру.

Что править (признаки «AI-почерка»)
- Подведение вместо факта: «не X, а Y», одно‑строчные «наводки», вступления «давайте разберёмся».
- Ритм по шаблону: списки из трёх, одинаковые начала предложений, тире как универсальный клей, каскад модалок.
- Надутость и заёмный авторитет: «эксперты считают», рекламные хвосты, размытые связи.
- Формат по шаблону: декоративные жирные метки, повсюду Title Case заголовков.
- Остатки чата и черновиков: приветствия, дисклеймеры «по ограничению знаний», описания прошлой версии вместо текущего поведения.

Процесс
1. Прочитать текст, отметить сильные проблемы.
2. Переписать, сохраняя смысл и границы; удалить лишь пустые обороты.
3. Сверить с исходником: не добавлено/не потеряно; рамки и неопределённость сохранены.
4. Вернуть итоговый текст. Пояснения — только по запросу.

Выход
- Вставленный текст: вернуть финальную версию без «оценочных» списков по умолчанию.
- Режим файла: редактировать только прозу и записать; вкратце описать изменения.
